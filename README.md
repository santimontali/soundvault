# SoundVault

A sound-library manager for game-audio designers. Browse and audition huge WAV libraries instantly, find sounds by name or by describing them ("distant thunder", "pasos en grava"), find sounds that contain or resemble a selection (Echo), edit and drag straight into your DAW, and organise everything into vaults and collections. Everything runs locally and offline.

- Architecture: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
- Verified use cases (Spanish): [docs/CASOS_DE_USO.md](docs/CASOS_DE_USO.md)
- All documentation, designs and research: [docs/README.md](docs/README.md)
- Building and sharing the installer: [DISTRIBUTION.md](DISTRIBUTION.md)

Development: `npm install`, then `npm start`. Tests: `npm test` (unit), `npm run test:engine` (engine in Electron), `npm run test:e2e` (the real app on fixtures).
