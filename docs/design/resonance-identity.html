SoundVault · identidad de la IA

Resonance, sin estrellita

Hoy la IA aparece como "AI" con el ícono spark, el cliché de cualquier producto. La propuesta: llamarla Resonance y darle una marca que salga del mundo del sonido, dibujada con las mismas reglas que el sprite (16 px, trazo 1.6, puntas redondas, currentColor) y con un solo acento lima, como la cerradura del cofre. Abajo hay cuatro direcciones, cada una en tamaños reales y en la interfaz. La 1 es la recomendada.

Dice qué hacés, no qué tecnología hay atrás. EchoSin cambios: conserva su nombre y su ícono de ondas. Escuchando

Estado animado para cuando el motor trabaja (analizando, arrancando, buscando). Es CSS puro: una clase listening en el svg.i y el símbolo del sprite hace el resto. Con prefers-reduced-motion no se anima: queda el diapasón quieto, en lima.

1Diapasón: las barritas nacen junto a las puntas y se alejan, en dos anillos. El diapasón no se mueve.
2Pico: el pico baja y vuelve a subir, como un filtro que respira.
3Simpatía: la barra central pega y las vecinas responden un instante después.
4Cóclea: un pulso recorre la espiral hacia el centro y el punto late.

Implementación

El símbolo ya está en el sprite de src/renderer/index.html como i-resonance, al lado de i-spark. Se usa igual que cualquier otro: icon('resonance', 'xs') en el chip, icon('resonance') en el panel y en el botón. Las barritas del anillo viven dentro del símbolo con opacidad 0: sin el CSS de abajo, el ícono es el diapasón quieto. Para animarlo, svg.classList.toggle('listening', ocupado). El CSS va en tokens.css, junto a las reglas de .i.

<symbol id="i-resonance" viewBox="0 0 16 16"><path d="M5.7 1.6v6a2.3 2.3 0 0 0 4.6 0V1.6M8 9.9v4.5"/><path class="rz-ring" d="M3.6 2.2v2.8M12.4 2.2v2.8" stroke-width="1.3" opacity="0"/><path class="rz-ring rz-ring-2" d="M1.7 3v1.2M14.3 3v1.2" stroke-width="1.3" opacity="0"/></symbol>
/* Resonance: "listening" state. Add .listening to the icon's <svg class="i">.
   The ring bars live inside the i-resonance symbol (opacity 0 when idle);
   inherited custom properties switch their animation on per instance. */
.rz-ring { animation: var(--rz-ring, none); transform-box: view-box; transform-origin: 8px 3.6px; }
.rz-ring-2 { animation: var(--rz-ring-2, none); }
.i.listening {
  --rz-ring: rz-ring 1.8s var(--ease) infinite;
  --rz-ring-2: rz-ring 1.8s var(--ease) .28s infinite;
}
@keyframes rz-ring {
  0% { opacity: 0; transform: scaleX(.9); }
  18% { opacity: .95; }
  70%, 100% { opacity: 0; transform: scaleX(1.1); }
}
@media (prefers-reduced-motion: reduce) {
  .i.listening { --rz-ring: none; --rz-ring-2: none; }
}
