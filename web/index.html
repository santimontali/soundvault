Echo Vault

Selecciona un fragmento.
Encuentra su eco.

CLAP convierte 0,3 segundos de audio en un vector de 512 dimensiones. Echo Vault lo compara contra cada región indexada y devuelve los fragmentos que suenan igual — timbre, textura y envolvente, no etiquetas. Arrastra sobre la onda.

Specs

Hoja de datos.

Motor semántico
LAION CLAP · htsat-unfused · ONNX Runtime (local)
Embeddings
512-D · normalizados L2 · 2.048 B por sonido, cacheados
Índice vectorial
HNSW (hnswlib) en background · brute-force como fallback inmediato
Latencia
5–8 ms sobre 70.000 vectores + 2 ms de ordenación
Base de datos
SQLite embebido (better-sqlite3) · metadata + embeddings
Decodificación
ffmpeg → mono 48 kHz float32 · WAV, AIFF, OGG, FLAC, MP3…
Editor de audio
Fades y crop con handles · preview en tiempo real
Integración DAW
REAPER (Lua) · drag & drop nativo al explorador
Privacidad
0 telemetría · 0 red · funciona desde el primer arranque
Plataforma
Windows 10/11 x64 · instalador NSIS + portable · licencia MIT
